# Moss

> 屏幕角落的一株苔。不记录你在做什么，只在你偏出去的时候变一下颜色。

一个自用的 AI 桌面伙伴。目标不是"更高效的待办工具"，是**一个知道你最近在忙什么、能在你偏出去时轻轻碰你一下、并且大部分时间不说话的东西**。

---

## 现在是什么状态

**做完了感知层的一半，还没有"助手"。**

- ✅ 每天扫所有 git 仓库，生成"今天干了什么"的总结
- ✅ 桌面前台窗口采集（进程、标题、空闲、浏览器 URL）
- ❌ 目标对齐——不知道该把提交归到哪个目标上
- ❌ 判断进度——不知道快了还是慢了
- ❌ 小人本身——一行代码都没写

不用误会：现在能跑的是**记忆**，不是**陪伴**。但记忆是陪伴的前提。

**接下来怎么建，写在 [`docs/v1-spec.md`](docs/v1-spec.md)**：Electron 球 + Python brain 的技术选型、严格目录结构、球的视觉与发光语义、观察层的归因算法、目标怎么变成回应、五道闸门的阈值、DDL 和接口契约，以及 P0–P2 每期的验收与中止条件。

## 快速开始

只装了 Python，没有别的依赖。

```bash
cd scripts

python digest.py --repos          # 看扫到哪些仓库、自动归到哪一类
python digest.py --dry-run        # 预览今天的总结
python digest.py                  # 写文件到 out/digest/
python digest.py --backfill 30    # 补齐过去 30 天
```

想同时记录桌面活动：

```bash
python observer.py                # 常驻，3 秒一采样
python report.py                  # 出当天的结构和分析提示词
```

在 `scripts/` 下新建 `digest_config.json`（或跑 `python digest.py --init`）可以改扫描目录、归类规则、输出仓库。

## 两个先读的判断

**① 只读 git，是因为它不会过期。**

读屏幕更丰富，但那些数据活不过一周——你今天半夜关掉电脑，明年再想看"上周三下午在干啥"，窗口标题早就没了。git 不会：`digest.py` 能一口气补齐过去 31 天，`observer.py` 一分钟都补不了。

先要一份不会骗人但偏薄的记录，再考虑加厚。

**② 不做评价。**

不写"显著提升"、不给效率分、不猜动机。脚本一开口替你下结论，这份总结就不能用来做决定了——你分不清哪句是事实。

## 名字

苔藓贴着地面长，不显眼，不抢养分，但会缓慢地覆盖过去。它的生长不是靠某一天的努力，是靠一直在。

这个助手也该是这样：侧坐在屏幕边上，自己忙自己的，你偏出去了它才动一下。
